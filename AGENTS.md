# report-generator

- PDF кидают прямо в `subjects/<предмет>/` (задание, лекции, что угодно вместе). Не сортировать. Не ждать вложения в чат.
- `/report` конвертирует все PDF в папке предмета, по тексту понимает что задание, остальное — контекст, выполняет работу.
- Эталон `subjects/<предмет>/sample.docx` только читать. Писать только в копию `lab-*/report.docx`.
- Не собирать Word с нуля. Копия эталона + клоны блоков.
- Выполнить **каждый** пункт задания. Не пропускать текст, списки, картинки из задания. Лекции — опора, не замена пунктов.
- Нет нужного MCP/приложения — подключить (Composio/MCP) или найти CLI на GitHub и поставить. Не останавливаться на «у меня нет Postman».
- Не пропускать визуальный осмотр PNG.
- Не использовать Composio для генерации Word. Готовый `.docx` локальный.
- Диаграммы: Mermaid, не image generation, если хватает кода.
- CLI-ошибки скриптов на русском. Оркестрация: скилл `/report`.
